В рамках проекта по оценке эффективности системы рекомендаций онлайн-магазина
здорового питания я определял, приводит ли новая нейросетевая рекомендательная система к
росту выручки по сравнению со старой (рекомендации на основе истории покупок). A/B-тест
проводился с 01.10 по 14.10.2023.
В качестве метрики выбрал среднюю выручку на пользователя (ARPU), поскольку суммарную
выручку групп напрямую сравнить t-тестом нельзя — математический аппарат теста работает
со средними значениями. Провёл разведочный анализ данных, изучил распределения и
выявил выбросы. С помощью моделирования проверил отсутствие ошибки Sample Ratio
Mismatch, затем отфильтровал данные, оставив только покупки за период эксперимента.
Для статистического анализа сначала проверил равенство дисперсий тестом Левена, после чего
применил t-тест Уэлча (ttest_ind с equal_var=False), поскольку дисперсии в группах различались
и размеры выборок не совпадали. Результат показал, что новая система значимо увеличивает
среднюю выручку на пользователя, поэтому рекомендовал эту систему рекомендаций.
Использовал Python (pandas, scipy.stats) и Jupyter Notebook. Главной сложностью стал
корректный выбор метрики-среднего для t-теста и учёт ограничений теста при неравных
дисперсиях и асимметричных распределениях.
